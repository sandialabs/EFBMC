Elastic Functional Alignment

We will now align the computer model output to the experiment. We will need the aligned data ftilde_train and the shooting vectors vv_train. Additionally we will need the shooting vector for the experiment. In this case, since we are aligning to the experiment warping function will be identity () and then the corresponding shooting vector vv_obs.
There is the option of the parameter lam in multiple_align_functions that restricts the amount of alignment. In some cases we will set this to a small value (e.g., 0.01) to remove heteroskedacity from the warping functions.
tt = linspace(0,1,nt);
out = fdawarp(y_train',tt');
lam = 0.01;
out = out.multiple_align_functions(ftilde_obs',lam);

Surrogate Model Fitting

Next, we will fit the BASS surrogate to the computer model and evaluate its performance. We use the mvBayes package due to its ability to introspect surrogates and their performance.
The choice of nBasis here is made from exploratory data analysis. It can also be chosen based on the percentage of variance explained from the functional principal component analysis (fPCA) decomposition. The parameter in mvBayes do perform this is propVarExplained.

Bayesian Model Calibration

We will now set up impala to perform the calibration. First we need to setup the parameter names and bounds on the parameters. impala sets uniform priors on the parameters based on their bounds.
input_names = {'theta0', 'theta1', 'theta2'};
bounds.theta0 = [0, 1];
bounds.theta1 = [0, 1];
bounds.theta2 = [0, 1];
We will no set up the calibration object and add the experimental data for the aligned data and shooting vectors. impala is set up to run multiple chains and do annealing so we set up a temperature ladder of 20 chains. We also set the chains to run for 4000 samples with a burn in of 2000 samples. The last line runs the calibration.
setup = CalibSetup(bounds, @cf_bounds);
 
model_ftilde = ModelmvBayes(emu_ftilde, input_names);
model_vv = ModelmvBayes(emu_vv, input_names);
 
setup.addVecExperiments(ftilde_obs', model_ftilde, 0.01, 20, ones(1,nt));
setup.addVecExperiments(vv_obs', model_vv, 0.01, 20, ones(1,nt));
setup.setTemperatureLadder(1.05.^(0:19));
setup.setMCMC(4000,2000,1,10);
out = calibPool(setup);
